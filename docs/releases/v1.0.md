# GMK104 Studio v1.0

The first public release: a native Linux screen-image/GIF uploader for the
ZUOYA GMK104, with a red/black/off-white Wayland/X11 Qt GUI.

## Downloads

- `GMK104-Studio-1.0.0-x86_64.AppImage`: portable Linux x86_64 application.
- `70-gmk104.rules`: install once for non-root USB access.
- `SHA256SUMS`: release-file integrity checks.
- `build-info.json`: exact Python/dependency versions used for this bundle.

The AppImage includes Python and Qt. It targets glibc-based Linux with an
Ubuntu 22.04-or-newer baseline. It does not install udev permissions.
See the README for installation and FUSE-less operation.

## Included

Black transparency, proportional black padding, animated preview, basic editing,
external-editor handoff, last 10 successful uploads, live settings readback,
and mandatory private settings backups.

## Limits and safety

Only the tested GMK104 wired interface, Custom1, one/two frames, and a global
500–1000 ms interval are supported. No Windows/macOS support or firmware flashing.
Settings backups do not contain the current animation or firmware.
