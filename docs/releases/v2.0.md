# GMK104 Studio v2.0

Screen editing and keymapping for the ZUOYA GMK104 on Linux.

## New in V2

- **Keymap tab:** automatically load the connected keyboard, edit four layers
  with a physical keyboard preview, and search for supported key assignments.
- Label the backlight/LCD switches, edit the knob press, and identify existing
  Fn/media/lighting/vendor codes with interpretation notes.
- Stage edits locally, review differences across every layer, explicitly confirm
  Apply, and verify the entire keymap after writing only changed mappings.
- Save private full-keymap backups before writes, refuse stale snapshots, and
  retain a permanent first-read recovery baseline.
- Restore the bundled captured defaults or load a checked backup for review.
  No firmware factory-reset or flashing commands are used.
- Preserve unidentified values, including unresolved `0xFFFF` entries.
- Improve margins, tabs, inputs and list spacing; keep the keyboard preview
  stable during restores and scroll compact layouts without overlaps.
- Remove horizontal scrolling from recent uploads; elide long names with full
  tooltips and inset Screen editor controls.
- Refresh the README with the full feature list and offline UI screenshots.

The Screen tab retains image/GIF uploads, black transparency, proportional fit,
editing/export, external-editor copies and the last ten successful uploads.

## Downloads and upgrade

- `GMK104-Studio-2.0.0-x86_64.AppImage`
- `70-gmk104.rules`
- `SHA256SUMS`
- `build-info.json`

Both tabs are included in the AppImage. The bundle targets Linux x86_64 on
glibc-based distributions, with an Ubuntu 22.04-or-newer baseline.
Existing history, preferences and backups keep their V1 locations. The same
narrow udev rule is required; do not run the app as root.

## Validation and remaining limits

An unchanged keymap word was written back and all 960 keymap bytes matched its
pre-write backup. The keyboard owner also reports successful changed keymap
writes. Restoration and persistence after power cycling are not yet verified;
this does not establish safety for every firmware revision or assignment.

Wired mode only. Screen uploads remain limited to Custom1, one/two frames and
500–1000 ms. Mouse bindings, macros, knob rotation remapping, arbitrary raw
keycode entry and a lighting-settings panel are not implemented. Vendor/extended
labels are interpretations where noted. Saved defaults are a captured keymap,
not manufacturer-certified factory defaults.

**Use at your own risk.** Independent reverse-engineered software, supplied
without warranty. Backups do not contain firmware or previous screen artwork;
an interrupted write can leave partial settings. No automatic retry or rollback.
Read [device safety](https://github.com/Geoffery10/GMK104-Studio/blob/v2.0/SAFETY.md)
and the [keymapping guide](https://github.com/Geoffery10/GMK104-Studio/blob/v2.0/docs/KEYMAPPING.md).
